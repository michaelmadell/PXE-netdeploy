# 1. Record architecture decisions

Status: accepted

## Context
The project makes several non-obvious choices (boot chains, builders, security
model) that future contributors, including future us, will question.

## Decision
Record significant decisions as short ADRs in `docs/adr/`, numbered, never
deleted. A reversed decision gets a new ADR that supersedes the old one.

## Consequences
Each ADR states context, decision, and consequences in under a page.
